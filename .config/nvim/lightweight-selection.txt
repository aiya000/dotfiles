## --- normal mode: 基本操作 ---
<C-c> / <C-c><C-c>               -- <C-c>をprefix化・二重押しで本来の動作
<C-g> / <C-g><C-g>               -- <C-g>をprefix化・二重押しで本来の動作
<CR> → o<Esc>                    -- normal modeでEnterを新行挿入に
<C-j>/<C-m> → <CR>               -- <CR>と同義
<C-[>/<Esc>/<C-l> → clear        -- ESC系キーでハイライトクリア等
<C-k><C-l>                       -- ハイライトを深くクリア
<C-k>o → e! %                    -- バッファを再読み込み
gG → ggVG / 'gG → ggVG"+y        -- 全選択・全コピー
q: → :                           -- q:でcmd-mode（:はcmdpaletteに割り当てているため）
( ) { } → zv付き                  -- fold展開しながら移動
<C-k><C-j>                       -- ハイライトクリア＆保存
<C-k>J → :wall                   -- 全バッファ保存
<C-]> → g<C-]>                   -- タグジャンプ（あいまい）
<leader>q → copen / <leader><leader>q → cclose -- quickfix開閉
Y → yg_                          -- 行末まで（EOLなし）ヤンク
g<C-]> / g_ → $                  -- g$相当
zs → zszh                        -- 水平スクロール
,, → 全バッファ内容をクリップボードへ
,< → 全バッファ内容を空に（リフレッシュ）
<C-x><C-n>/<C-x><C-p>           -- デフォルト補完
/ → /\m / ? → ?\m                -- magicモードで検索

## --- normal mode: 検索 ---
g* → カーソル移動なし検索
n/N → 常に前後方向固定・fold展開
* / #                            -- fold展開付きsearch

## --- normal mode: Q（バッファ閉じ系）---
Q                                -- quickfix/gin/diff等の特殊バッファを閉じる

## --- normal mode: fold ---
h/l → foldが閉じていれば zo      -- fold開閉優先移動
zj/zk → fold開きながら移動
zC → zM / zA → zR               -- 直感的エイリアス

## --- normal mode: ウィンドウ・バッファ・タブ ---
<Space>h/j/k/l → <C-w>移動
ghR/ghq/ghQ/ghc/ghC/gho 等       -- ウィンドウ/タブ操作
<C-w>* → <NOP>（誤操作防止）
gh → <NOP>（prefix化）
<C-s>N/<C-s>P                   -- ウィンドウ移動
<C-n>/<C-p> → タブ移動ループ
<C-s>n/<C-s>p → タブを移動しながら移動モードへ

## --- normal mode: ターミナル ---
<leader>v / <leader><leader>v    -- vertical/horizontal splitでシェル起動
<leader>V / <leader><leader>V    -- 現在ウィンドウ/新タブでシェル起動
