# レビューログ

`write-tech-note` で書いた記事が受けたレビューの記録。
新しいエントリは `refine-write-tech-note` スキルが末尾に追記する。手で編集するときも、この形式を守る。

各エントリは次の形。

- **記事**: ファイル名（この時点でのパス）、型、行数
- **レビュアー**: Zenn AIレビュー / 人間（役割） / 本人の推敲差分
- **判定**: レビューの結論をそのまま（「改善点: 特にありません」など）
- **褒められた点 → 対応するルール**: 一行ずつ。ルールは `style-guide.md` の §番号や `SKILL.md` の要件番号で指す
- **指摘された点 → 直したこと**: 一行ずつ。ルールを足した／変えた場合は、どのファイルのどこか
- **制作時の失敗**: レビューには出ていないが、書いている最中に踏んだもの（捏造しかけた出力、個人情報の混入、拒否されたコマンド）。これも `refine` の対象

ルールへ反映済みのものだけを残す。「反映していない指摘」は `TODO:` を付けて残し、次の `refine` で拾う。

## 2026-09-06 `ps-mem`（型C）
