## Setup

```shell-session
$ pushd ~ ; ln -s ~/.dotfiles/AGENTS.global.md AGENTS.md ; popd
```

## Local AGENTS.md

You can set up a local AGENTS.md.
Create `~/AGENTS.local.md`.
`~/.dotfiles/AGENTS.global.md` contains an instruction to load it.

- Example: `~/.dotfiles/AGENTS.local.md.example` (drop the `.example` suffix when naming the actual file)
